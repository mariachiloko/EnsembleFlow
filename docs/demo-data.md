# EnsembleFlow Demo Data

## Purpose

This app can be easier to review if it starts with believable sample content.

## Good Demo Defaults

- one director account
- one member account
- one ensemble
- two or three sections
- a few assignments with due dates
- a handful of submissions
- several comments on one submission
- a few unread notifications

## What Should Stay Fake

- sample names
- sample uploads
- sample comments
- sample notification text

## What Should Stay Real

- the upload flow
- the role checks
- the DynamoDB records
- the S3 object keys

## How To Use It

Use demo data only for preview and walkthrough purposes. Real users should create their own profiles, ensembles, sections, and uploads after sign-in.
