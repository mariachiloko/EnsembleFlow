# EnsembleFlow Workflow

## Core Loop

1. A director or leader creates an assignment for an ensemble.
2. Members upload a practice submission for that assignment.
3. The leader reviews the submission and leaves feedback.
4. The submission status is updated so the group can see progress.
5. Members can open a section thread to message one another or start a group conversation inside their section.

## Why It Matters

- Assignments make expectations explicit.
- Submissions create accountability.
- Feedback helps the ensemble improve without needing a separate communication tool.
- Section conversations give members a simple place to coordinate without exposing the whole ensemble to every message.

## Current Scope

The first version focuses on:

- profiles
- ensembles
- assignments
- submissions
- feedback
- section-scoped feeds
- comments
- notifications
- section conversations and group messages

The app does not yet include advanced reporting, attendance tracking, or AI analysis.
